# ELECTRON LIBARY
Электрондық кітапхана — кітаптарды қосуға, сақтауға, өңдеуге және жоюға арналған бағдарлама. Пайдаланушылар кітаптарды атауы, авторы, шыққан жылы және жанры бойынша іздей алады. Жоба Python және SQLite технологиялары арқылы әзірленеді.

# Электрондық кітапхананың негізгі функциялары
Кітап қосу — каталогқа жаңа кітап енгізу.

Кітаптар тізімін көрсету — барлық сақталған кітаптарды қарау.

Кітап іздеу — атауы, авторы, шыққан жылы немесе жанры бойынша іздеу.

Кітап мәліметтерін өңдеу — кітап туралы ақпаратты өзгерту.

Кітапты жою — каталогтан қажетсіз кітапты өшіру.

Деректерді сақтау — кітаптар туралы ақпаратты SQLite дерекқорында сақтау.

Кітап туралы ақпаратты қарау — атауын, авторын, шыққан жылын және жанрын көрсету.

README.md құжаттамасы — бағдарламаны орнату және іске қосу нұсқаулығын ұсыну.
